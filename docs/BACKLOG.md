- **Per-registration classification hint** (2026-09-27, lead's ruling on the target-lookup fix): when the command-line lookup fails, a wake now presses Enter once and says so, so a Codex or Copilot session may need Enter by hand. Both field cases on the Y530 (pid 150184 at 07:15 and 07:16 UTC, pids 30448 and 23072 at 08:08 UTC) had been classified with confidence minutes earlier under the same registration. A hint stored on the registration (registration id plus pid, set only from a confident answer, used only when a lookup fails, cleared on leave or rejoin) would have saved both without serving a stale answer, on the argument that a pid cannot change process under a live registration. That argument is the thing to test: a registration can outlive its process (the agent exits without leaving, and the pid is reused by a new process before the stale sweep), so the gate must judge the pid-reuse case, for example by storing the process start time with the hint and checking it with the same query that failed. The cost fixes (pwsh, one query per burst, 10 s) stay the primary defence.
