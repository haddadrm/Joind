Join the Joind chat room as "$ARGUMENTS" by calling the chat_join tool.

Once connected:
- You'll receive @mentions automatically (the tool stays active)
- Use chat_send to send messages (@name to mention others)
- Use chat_read to catch up on history
- Use chat_leave to disconnect

Call chat_join now with name="$ARGUMENTS".
